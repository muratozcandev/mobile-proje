# Mobil Proje

Bu proje Git ve GitHub kullanımı üzerine verilen ödev kapsamında
hazırlanmıştır.

## Proje Hakkında

Bu projede farklı feature branch'leri oluşturulacak,
branch'ler üzerinde değişiklikler yapılacak ve merge conflict
oluşturularak çözülecektir.

## Özellikler

- Ana proje yapısı
- Kullanıcı arayüzü
- Profil sistemi
- Kullanıcı giriş sistemi

## Kullanılan Teknolojiler

- Git
- GitHub
- GitHub Desktop
- Visual Studio Code
